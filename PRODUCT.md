# Product Definition

## Positioning
**Composable Incident Response Modules** is a reusable workflow-layer reference product for software vendors and system integrators that need mature incident-response logic without rebuilding it from scratch.

## Product promise
A customer can take individual modules, combine them into scenario workflows, adapt the terminology and rules to its own organization, and implement the result inside its own software stack.

## What is reusable
- Workflow structure
- Module boundaries
- State transitions
- Data concepts
- Transparent resource matching
- Task lifecycle
- Field-feedback pattern
- Coordination and timeline concepts
- Reporting concepts
- Scenario packages

## What is intentionally customer-owned
Infrastructure, databases, APIs, authentication, maps, communications, integrations, deployment, security controls, compliance, production operations and support.

## Commercial forms
- Single module
- Module bundle
- Scenario package
- Full workflow
- White-label / OEM
- Commercial license
- Strategic partnership
- Potential asset acquisition
