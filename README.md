# Composable Incident Response Modules

A vendor-neutral reference product for reusable incident-response workflows.

## Core principle
**Build once. Split anywhere. Combine as needed.**

The MVP demonstrates a modular workflow layer that can sit above a customer's existing maps, communications, identity, data, and infrastructure.

## Modules
1. Incident
2. Verification
3. Resource
4. Task
5. Dispatch
6. Field Feedback
7. Coordination
8. Timeline
9. Resolution
10. Reporting

## Workflow
Incident Discovery → Verification → Decision → Resource Matching → Task → Dispatch → Field Feedback → Resolution → Closure → Reporting

## Demo scenarios
- Wildfire Response
- Search & Rescue
- Infrastructure Incident

All demo data is fictional.

## Run locally
Open `index.html` in a browser, or run a simple static server.

No database, external API, GIS engine, GPS, sensor, drone, communications, authentication, cloud deployment, or production SLA is included in this MVP. Those are intentionally left to a future implementer/customer.
